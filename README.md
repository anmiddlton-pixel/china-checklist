# Чек-лист поступления в Китай

Статическая страница для GitHub Pages. Отметки сохраняются в localStorage браузера. PDF создаётся на устройстве из исходного шаблона с текущими галочками.

## Публикация
1. Создайте публичный репозиторий china-checklist.
2. Загрузите index.html, папку assets и .nojekyll в корень репозитория.
3. Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. Адрес: https://ВАШ-ЛОГИН.github.io/china-checklist/

Для локального просмотра: python3 -m http.server 8765 из этой папки. Откройте http://localhost:8765.

Отметки не синхронизируются между устройствами. PDF — снимок на момент скачивания. Тексты исходного чек-листа сохранены без фактологической редакции.

Библиотека pdf-lib 1.17.1 распространяется по лицензии MIT (assets/pdf-lib.LICENSE.md).
